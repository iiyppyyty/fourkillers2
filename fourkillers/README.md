# Four Killers: глава 1А (ИИ мобов)

Fabric 1.20.1, нужен Fabric API 0.92.2.

## Что умеет
- Зомби, скелеты, крипы, пауки и ведьмы теперь не знают, где вы, пока не заметят.
- Зрение: угол 120 градусов, 22 блока (присед вдвое меньше, в темноте на четверть меньше), стены закрывают обзор.
- Слух: бег слышно с 14 блоков, ходьбу с 6, присед почти не слышно. Удары и ломание блоков шумят.
- Состояния: спокоен, подозревает (стоит и смотрит), ищет (идёт к месту, где вас заметил), атакует.
- Удар по моб, который вас не заметил, наносит x3 урона.
- Частицы над головой: дым = подозревает, белые искры = ищет, красные = атакует.
- Команда `/fkdebug` включает и выключает частицы.

## Как собрать
1. Облако (без установки): загрузите папку проекта на GitHub, вкладка Actions, запустите build, скачайте jar из Artifacts.
2. На ПК: поставьте JDK 17 и IntelliJ IDEA Community, откройте папку, дождитесь импорта Gradle, затем Gradle -> build. Jar будет в build/libs (берите файл без `-sources`).

## Как ставить
Положите jar в папку mods вместе с Fabric API 0.92.2 (Fabric Loader для 1.20.1).

## Как проверить
1. Подкрасться присевшим сзади к зомби и ударить: сообщение "Удар со спины".
2. Пробежать рядом: мобы должны идти проверять место, а не сразу атаковать.
3. Встать перед мобом: он должен подозревать, а потом атаковать.
4. Спрятаться за стеной: после потери из виду моб ищет вас, потом успокаивается.
